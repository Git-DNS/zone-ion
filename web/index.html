Rules that keep the zone fair

01

GitHub sign-in

A GitHub account is required. The issue author is the account recorded in the ledger; a signed file alone is not enough.

02

One name per 48 hours

Each account may register one second-level domain every 48 hours. Subdomains of a domain you own are unlimited.

03

Ownership is a key

Updates and subdomains must be signed by the same ed25519 key. The zone bot verifies the signature before every commit.

04

Everything is public

Zone files, the registration ledger and the bot source are in one public repository. History is the audit log.

.ion is a GitDNS root zone. Records resolve through any GitDNS resolver.
